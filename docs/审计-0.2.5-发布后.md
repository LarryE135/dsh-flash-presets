## 六、发现与处置

### 已修 1：行尾断言把构建产物当源码扫

本地为发 Release 生成 `dist/dsh-flash-presets-v0.2.5.zip` 后，`verify-presets` 的 `eol=lf 的文件无 CRLF` 断言把它当文本扫了一遍，**报校验失败**（连带 selftest 4 项红）。

处置：
- 校验器跳过 `dist/`、`.cache/`、`node_modules/`、`.git/` 与二进制扩展名（zip / png / gz / ttf / pdf / mp4 等）；
- 把 Release 产物移出仓库树（现放在 `../dsh-flash-presets-dist/`）。

教训：校验器扫的是**工作树**而不是**受版本控制的文件**，遇到本地构建产物就会误报。

### 已修 2：README 文档索引未跟上
