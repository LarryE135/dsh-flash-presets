## 4. 新增的运行时守卫

`scripts/verify-runtime.mjs`：

- 有 `dump.txt` 参数时校验该文件，没有时自己跑 `dsh --profile <p> --dump-config`
- PATH 里没有 `dsh` 时**打印 skip 并退出 0**（三平台矩阵不装 CLI，不该因此变红）
- 断言：预设进入合成结果、order、阈值、保留预算、规则条数、PTC、三个预设各一次

CI 的 `bundle-install` job 里，在原有“id 出现过”的循环之后新增一步跑它；本地可用 `npm run verify:runtime`（需已装预设）。
