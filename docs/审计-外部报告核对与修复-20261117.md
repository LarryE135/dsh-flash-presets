## 5. 审计方给的三条「需要在 rc 上核实」

1. **会话事件形态** —— 已核实：宿主 `dsh-session` 发布 `{type,seq,time,data}`，`dsh-acp` 也按 `event.data.*` 读，`user/message` 不含 turn。所以 A-P1-1 成立，不是 alpha.3 的旧行为。
2. **webServer 是否统一鉴权** —— rc 的 `dsh-api-gateway` 未见对插件私有路由的统一 Host 校验，本地按「没有」处理（已加白名单）。
3. **回合收尾是否 await `agent/turn-stopping`** —— rc 里 `agent-loop` 仍是 `await dispatch.serial(...)`，所以交付门挂起会卡住整个回合，A-P1-5 按「严重」处理。
