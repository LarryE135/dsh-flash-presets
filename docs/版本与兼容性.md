# 版本与兼容性

## 版本对应

| dsh-flash-presets | DSH | 说明 |
|---|---|---|
| 0.2.1 | 0.2.1-rc.2 | 当前分支：v3（lean-v3）定稿；三预设安装器/校验器齐备 |
| 0.2.0 | 0.2.0 | 声明为组合包；v2 发布 |
| 0.1.0 | 0.1.7-rc.1 ~ 0.2.0 | 首个发布；v1 |

预设机制自 DSH **0.1.7-rc.1** 起改为"插件行 + 用户补丁层"；本仓库 0.2.x 全部基于该机制，故与 0.2.1 天然对齐。

## 兼容性矩阵

| 项目 | 状态 | 依据 |
|---|---|---|
| DSH 0.2.1-rc.2 | ✅ | 模拟安装后 `--dump-config` 合成出 v1/v2/v3 三行；`--check` 一致 |
| DSH 0.1.7 ~ 0.2.0 | ✅ | 同一插件行机制，安装器逻辑未变 |
| DSH < 0.1.7 | ⚠️ | 仅 v1 有 `presets/legacy-0.1.5/` 目录式回退 |
| profile web | ✅ | live reload，刷新即生效 |
| profile desktop / headless / acp | ✅ | 需重启（provider 补丁层只在启动时读取） |
| Windows PowerShell | ✅ | `scripts/install.ps1`，与 sh 版共用合并器 |
| Linux / WSL | ✅ | `scripts/install.sh` |
| macOS | ⚠️ | 脚本按 bash 3.2 兼容写（变量后接非 ASCII 必须 `${var}`），但**未在真机验证** |
| 第三方 YAML 解析器 | ⚠️ | 补丁含 `!!js` 标签，非 DSH 解析器会报 unknown tag |

## 模拟安装回归（0.2.1 实测）

```bash
SIM=/tmp/dshsim
mkdir -p $SIM/profiles/web && echo '[]' > $SIM/profiles/web/cordis.patch.yml
DSH_HOME=$SIM bash scripts/install.sh --profile web      # 写入托管块
DSH_HOME=$SIM node scripts/verify-presets.mjs            # 逐预设断言
dsh --profile headless --patch $SIM/profiles/web/cordis.patch.yml --dump-config | grep preset-flash-lean-ptc
DSH_HOME=$SIM bash scripts/install.sh --profile web      # 重复安装：托管块仍为 1 份
DSH_HOME=$SIM bash scripts/install.sh --profile web --uninstall
```

断言点：

- 托管块恰好 1 份（BEGIN/END 各 1），三次预设行齐全；
- `--dump-config` 中 `preset-flash-lean-ptc-v1/v2/v3` 全部出现；
- 重复安装不产生第二份块；
- 卸载后块与预设行计数归零；
- `verify-presets.mjs` 逐预设核 order / 规则条数 / 压缩阈值 / 保留预算 / 裁剪阈值 / PTC / tool-workflow，全绿。

## 升级路径

0.2.0 → 0.2.1 是**纯追加**：新增 v3 与多预设支持，v1/v2 的定义与 order 未变，已安装的 profile 只需重新安装一次即可获得 v3。
