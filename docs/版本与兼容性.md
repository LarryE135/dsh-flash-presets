## 模拟安装回归

```bash
SIM=/tmp/dshsim
mkdir -p $SIM/profiles/web && echo '[]' > $SIM/profiles/web/cordis.patch.yml
DSH_HOME=$SIM bash scripts/install.sh --profile web
DSH_HOME=$SIM node scripts/verify-presets.mjs
dsh --profile headless --patch $SIM/profiles/web/cordis.patch.yml --dump-config | grep preset-flash-lean-ptc
DSH_HOME=$SIM bash scripts/install.sh --profile web --uninstall
```

断言点：

- 托管块的 BEGIN 与 END 各一份，三个预设行齐全。
- `--dump-config` 中 `preset-flash-lean-ptc-v1`、`v2`、`v3` 全部出现。
- 重复安装不产生第二份托管块。
- 卸载后托管块与预设行计数归零。
- `verify-presets.mjs` 逐个预设核对 order、规则条数、压缩阈值、保留预算、裁剪阈值、PTC 与 tool-workflow。

## 升级路径

0.2.0 到 0.2.1 是纯追加：新增 v3 与多预设支持，v1 与 v2 的定义、order 均未改动。已安装的 profile 重新安装一次即可获得 v3。

## 安装渠道验证（2026-10-20）

在临时 `DSH_HOME` 下用插件管理器实装过两条渠道，均成功：

| 渠道 | 命令 | 结果 |
|---|---|---|
| 本地目录 | `dsh plugin --profile web add file:/path/to/dsh-flash-presets` | 写入 `dsh.profile.bundles`，`--dump-config` 见 v1/v2/v3 |
| GitHub | `dsh plugin --profile web add github:LarryE135/dsh-flash-presets` | 同上，pnpm 解析 git 依赖耗时约 3 s |
| npm 包名 | `dsh plugin --profile web add dsh-flash-presets` | 0.2.2 起可用，解析 `latest`；要可复现请写 `@0.2.4` |

GUI 的「插件 → 添加插件」等价于这些渠道的命令行形态：填裸包名、GitHub 地址或本地目录都可以。

npm 通道已于 2026-10-21 打通（0.2.2 起），`files` 字段包含 `scripts/` 与 `docs/`，因此从 npm 安装同样拿得到手动安装脚本；tarball 共 50 个文件（解包 390 425 B ≈ 381 kB；本地 `npm pack --dry-run` 实测压缩后约 140 kB），不含 `dist/` 也不需要构建步骤。数字按 registry 上 0.2.5 的 `dist.fileCount` / `dist.unpackedSize` 实测。
