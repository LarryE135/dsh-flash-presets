## 1. 结构与打包

- 顶层 11 个条目：presets/、scripts/、docs/、plugins/、candidates/、marketplace/、.github/、cordis.patch.yml、README.md、LICENSE 等。
- package.json 的 files 是白名单，只放 cordis.patch.yml、三个预设、scripts/、docs/、README、LICENSE——**plugins/、candidates/、marketplace/ 不进 npm 包，符合预期**。
- 但 README 的「仓库结构」代码块没列这三个目录，读者会以为仓库只有预设。candidates/、plugins/ 是 2026-10-23 新增的实验资产，marketplace/ 更早，属于文档滞后。已补。

## 4. 安装 / 卸载

- scripts/selftest.sh 实跑：**25 项通过，0 项失败**（版本口径 v0.2.2）。
- install.sh 与 install.ps1 共用 merge-presets.mjs 的托管块机制；CI 用两次安装断言幂等（托管块标记出现 2 次），并单独断言「卸载后用户自写 patch 仍在」。
- 0.1.7 以前的目录式回退只剩 v1，代码路径在 CI 里有独立步骤覆盖。

## 5. CI 与供应链

- 矩阵：ubuntu / windows / macos；14 个步骤，覆盖 bash 与 PowerShell 两条安装路径、旧版目录回退、卸载、自测、静态检查、组合包一致性。
- action 全部钉 SHA（actions/checkout@11bd71…、actions/setup-node@39370e…），不可变引用。
- Node 版本双轨：verify 用 20，安装断言用 24（注释说明 dsh CLI 在 Node 20 下静默退出）。
- **缺最小权限**：workflow 没有 permissions:，GITHUB_TOKEN 继承仓库默认值。已补 contents: read。
- 本次新增「预设文本审计」步骤，与本地 npm run verify 同一脚本。

## 6. Git 卫生

- 受控文件 42 个，无 >100 KB 文件，无二进制，.gitignore 覆盖 *.local.*、.credentials.yaml。
- 密钥模式扫描（sk-、ghp_、AKIA、PRIVATE KEY）无命中。
- 7 个标签，v1.0.0/v1.0.1/v1.1.0 与 v0.1.0/v0.2.x 时间交错（1.x 早于 0.1.0），已在 README 说明是同一代折叠。
- 本地遗留 pr3-review 临时分支（审阅 PR #3 时建的）已删。

## 7. 跨平台

- .gitattributes 钉 * text=auto eol=lf 且对 *.sh/*.mjs 单独钉 LF，避免 Windows 克隆出现 CRLF shebang 崩溃。
- check-bash32-cjk.mjs 守 macOS bash 3.2 把 $p（ 当变量名的坑；check-ps1.mjs 静态审查 PowerShell 的 BOM、完成文案、标签守卫。
- 已知缺口：macOS **真机**未验证（CI 只跑标准 macOS runner 的 bash/pwsh），README 已如实声明。
