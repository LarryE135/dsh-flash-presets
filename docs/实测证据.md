数据来自 DSH headless + PTC 的批量运行（2026-10）。计费口径为会话事件中 `inputTokens + cacheReadTokens` 的累计和；「比值」指相对官方基准耗时的倍数，越小越好；「满分」指官方样例全部通过。

每组样本量为 2 到 3，结论按方向读。本页记录的是试过什么、哪些没有成立，不是排行榜。

## v4 / v4-b 候选否决记录（2026-11-01，headless + WB Proxy，办公基准 v5）

两个候选都是在 v3 之上**只加规则**：v4 加验收门（要求产出 P0-EXEC 可执行验收清单），v4-b 加预算刹车（20 轮即交付）。三次实验的结论一致指向否决。

### v4（验收门）· 全 8 题 n=2

质量零变化，成本翻倍：Token 合计 **+117%**，Q 与逐维度完全一致。规则被完整执行（产物里确有 P0-EXEC.yml），但没有人因此改对答案。

### v4-b（预算刹车）· 4 道重尾题 n=5

### 三条结论

1. **persona 规则改不动正确性。** 四次实验（v4 n=2、v4-b n=2、n=5、n=8×3）里 Q 与六维度、乃至坏单元格数**逐项相同**——同题无论加不加规则，模型给出的答案一样，只是绕路方式不同。
2. **成本效应不可复现。** 同一题在不同轮次会给出相反的符号（O07：n=2 时 +153%、n=5 时 −33%、n=8×3 时中位 −33% 但均值 +3.8%）；单次重尾 run 可占总量 40% 以上。加规则改变的是轮数分布，方向不可预测。
3. **判定标准要改。** 后续 A/B 应以「轮数分布 + p95 Token + 符号检验」为准，重尾题 n ≥ 5，且总量统计前先剔除离群；只报均值和总量的结论不成立。
