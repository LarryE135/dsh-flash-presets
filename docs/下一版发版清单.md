## 3. 真要发时的顺序（照 `docs/PUBLISHING.md`）

1. **定版本号**：改动含新功能（交付门、优化 A 独立行）+ 行为变化（install 统一入口），建议 `0.4.0`。**注意版本号不能再叫 `0.3.1`** —— 那个 tag 已占位（冻结规则不允许移动/删除），所以最小可用号是 `0.3.2`。
2. **同步五处版本号**：`package.json`、`marketplace/plugin.json`、`docs/版本与兼容性.md` 版本表、`docs/CHANGELOG.md` 新章节、README 顶部「当前版本」+ 三通道安装命令。
3. **`npm publish`**：先 `npm whoami` 确认 token（0.3.0 之后曾出现 E401，凭据可能已过期，需要重新 `npm login`）。
4. **打 tag + Release**：`git tag -a vX.Y.Z`；注意仓库规则 `freeze released tags`（`refs/tags/v*` 禁 update/deletion，无 bypass actors），**tag 一旦推上去就不能改**，先在本地核对再推。
5. **发完复核**：`npm view dsh-flash-presets@X.Y.Z gitHead` 应等于 tag 提交；`npm pack` 文件数与本地一致；README 里的安装命令能真装上；本条清单第 1 节的表逐行确认已在包里。
