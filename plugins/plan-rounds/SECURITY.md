# Security Policy

dsh-plan-rounds is a session-scoped planning-round control plugin: a /plan-rounds 0|2|4
command, a planRounds projection and a matching system-prompt contract. It adds no network
access, no filesystem writes and no process execution.

Report vulnerabilities through GitHub private vulnerability reporting on
<https://github.com/LarryE135/dsh-flash-presets/security/advisories/new>. Expect an
acknowledgement within 7 days.
