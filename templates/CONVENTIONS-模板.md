# CONVENTIONS 模板（沉默契约清单）

用途：在写任何验收项之前，先把「两种都说得通、选错就会产生看起来对但坏了」的约定显式写死。
每条必须有第三列：**怎么测出违规**（符号 / 比例 / 图像性质），否则不算约定，只是陈述。

| ID | 约定 | 理由 | 违规如何被测出 |
|---|---|---|---|
| C1 | 坐标轴朝向：+X → ?，+Y → ?，+Z → ?；地面 y=? | | 投影三个标记点，检查屏幕方向符号 |
| C2 | 水平拖拽：右拖 dx>0 → 相机方位角变化 ?（物体跟手 / 反向） | | 拖 200 px 后读方位角，符号与幅度 |
| C3 | 滚轮：deltaY>0 → 拉远还是拉近；半径夹紧区间 | | 连发 3 次 ±100，读半径变化方向 |
| C4 | 纵向拖拽：dy>0 → 极角增减；穿地/翻转的夹紧值 | | 拖 100 px 后读极角与相机高度 |
| C5 | 单位：长度 / 时间 / 速度的基准（秒 vs 毫秒、px vs 世界单位） | | 关键物理量的实测区间（如落体 10–25 s） |
| C6 | 原点与枢轴：根在何处；轨道目标点；几何是否烘焙到世界坐标 | | 包围盒 min.y / center.x 区间 |
| C7 | 投影：透视还是正交；fov 是垂直还是水平；near/far；默认距离 | | 读 fov/aspect，检查主体占画面高度比例 |
| C8 | 色彩空间与色调映射：sRGB / linear；toneMapping 是否启用 | | 读渲染器字段；采样背景像素值 |
| C9 | 暂停语义：暂停时冻结哪些状态；相机是否仍可操作 | | 暂停 1.2 s 两帧像素差 < 0.1%，仿真时间不增长 |
| C10 | 诊断接口：暴露哪些只读字段（方位角/极角/半径/fov/计数/包围盒/时间） | | 无此接口则以上全部无法判定 |

## 填写要求

- 每条都要能在 5 分钟内用脚本判定，判不了的改成可判定的形式。
- 有争议时**写下来**，不要靠实现者的习惯：方向、符号、单位是最高频的翻车点。
- 与产品需求冲突的约定（例如「落花要稀疏」vs「花量越大越好」）在 AMBIGUITIES 里单列，不要藏在约定里。
