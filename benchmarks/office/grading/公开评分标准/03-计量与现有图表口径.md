# 计量与现有图表口径

## 质量与资源消耗分别报告

质量分、严格通过率与步数、Token、时间分开呈现。不将质量乘以节省率合成一个总排名，不因事后得分改变 Token 权重。两版任务集分别展示。

## Token 与缓存

标准归一化为三个互斥类别：未缓存输入、缓存读取、输出。

含缓存总 Token = 未缓存输入 + 缓存读取 + 输出。

不含缓存小计 = 未缓存输入 + 输出。

若日志输入字段已包含缓存读取，先减去缓存得到未缓存输入；若输入不含缓存，则直接使用。输出应覆盖生成及推理消耗；已有包含关系时不重复相加。缓存写入或其他类别需要说明归属，无法完整覆盖时标为计量不完整。

保留逐请求原始日志及字段映射；纳入所有声明会话、子会话、重试和失败消耗。累计日志应按会话差分，避免把累计值重复加总。解析一致不等于供应商认证完整性；字段语义与导出完整性需另行核实。

每份有效交付 Token = 该冻结批次全部消耗 / 严格有效交付数；失败消耗保留在分子，零有效时留空。只有批次方法有效且计量完整才报告正式总量比较。若换算费用，使用明确日期与实际输入、缓存、输出费率；原始 Token 数不等于费用。

## 步数与时间

步数须注明计数单位及任务归属方法。执行器步骤数、工具调用数、模型请求数不可默认为同一指标。

时间须注明是任务串行总耗时、会话起止跨度还是并发墙钟；各模式必须使用一致定义才适合严格时延比较。不得用并发墙钟与逐题耗时之和直接比较。

## 现有宣传资料包实际口径

现有图表是五轮记录均值，不是本包重新测量。Token 包含缓存读取；这项声明不代替原始日志字段和完整性的独立核验。

| 版本与指标 | 实际来源或处理方式 |
|---|---|
| v5 分项步数 | 已发布的五轮均值 |
| v5 每轮总步数 | 各包五次执行汇总除以5：标准模式404/5、PTC288/5、lean-v3 168/5 |
| v5 每轮Token | 各结果包五轮会话总量的平均 |
| v5 耗时 | 标准模式取结果报告中精确到0.1分钟的五轮记录；PTC和lean-v3取各自执行统计的每轮记录 |
| v5.5 总步数、Token、耗时 | 各模式五次执行记录均值；耗时为会话起止跨度 |
| v5.5 分项步数 | 标准模式为步骤分摊值；PTC为直接任务归属值；lean-v3为步骤关键词折算值 |

v5 会话执行范围与计时字段来源不完全一致，其耗时仅表示各包记录值。v5.5 分项步数含分摊或估算，不能当作全部直接观测的任务步骤，也不保证与每轮总步数完全等价。宣传材料引用这些图时，应保留这类必要口径说明。

v5 历史结果报告称五轮11个交付文件逐行一致；v5.5 历史资料记载有限文本歧义。上述描述不是本包新增的严格通过率证据。本包未重评历史交付，也未生成新的质量或效率结论。

## 建议随结果保留的记录

版本、任务、预设、运行编号、匹配数与分母、任务分、严格通过标志、方法有效性、未缓存输入、缓存读取、输出、步数定义、计时范围、原始日志及歧义裁定记录。
