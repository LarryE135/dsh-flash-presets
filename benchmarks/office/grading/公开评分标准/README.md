# 日常办公基准测试 v5 / v5.5 评分标准

本包为已有宣传资料包的独立补充，整理于 2026-10-31。包含可公开的评分规则、汇总公式与计量说明；不含真值、答案、评分器代码或私有评测包。

## 文件

- 01-v5评分标准.md：六维质量分、严格有效交付、汇总规则。
- 02-v5.5评分标准.md：单元格精确匹配、五任务等权、exact 判定。
- 03-计量与现有图表口径.md：Token、缓存、步数、时间及已发布图表的适用边界。
- 文件校验.json：本包文件及依据文件的 SHA-256，方便确认版本。

两版使用不同任务集与评分函数，必须分别报告。v5.5 不能套用 v5 的六维权重，也不能把两版质量分合成一个总排名。

本包是规则说明，不是重新评分报告；不会因整理说明而将历史结果升级为严格通过、完整计量或同条件时延实验。正式复评仍需评测方持有对应私有真值、原始交付与日志。
